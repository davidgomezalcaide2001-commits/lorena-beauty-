# Prompt para generar la web — Lorena Sánchez Hair & Beauty

Úsalo tal cual (en Claude, v0.dev, o cualquier IA generadora de webs) para crear o regenerar el sitio.

---

**Prompt:**

Crea una página web de una sola página (HTML/CSS/JS en un solo archivo, sin frameworks) para un negocio real:

**Negocio:** Lorena Sánchez Hair & Beauty — peluquería boutique especializada en pelo rizado, color y tratamientos capilares.
**Ubicación:** Calle Rda., 24, Rincón de la Victoria, Málaga (pueblo costero).
**Teléfono:** 611 39 19 20
**Horario:** Lunes a viernes 9:00–14:00, sábado y domingo cerrado.
**Valoración:** 4,9★ en Google (33 reseñas), sin web propia actualmente.
**Posicionamiento:** estudio pequeño e íntimo, atención muy personalizada, nada de cadena ni citas en cadena. Conexión visual con el entorno costero del pueblo.

**Frase/titular principal (hero):**
En vez de un concepto abstracto, usa una imagen concreta y visual de transformación: **"Del rizo indomable a la ola perfecta."** — debe transmitir el antes/después de una melena rizada trabajada con técnica, con la imagen del mar de fondo (Rincón de la Victoria).

**Secciones que debe incluir:**
1. Hero con el titular anterior + subtítulo breve + botón de llamada/reserva.
2. "El estudio" — quién es Lorena, por qué es un espacio pequeño e íntimo.
3. "Servicios" en tarjetas: color y mechas, especialista en rizos, tratamientos capilares, cejas y microblading.
4. "Reservar cita" — selector de servicio/día/hora, pensado para conectarse después a Cal.com o Calendly (dejar el diseño listo para incrustar ese widget real).
5. "Opiniones" — 3 testimonios cortos, parafraseados, sin nombres reales.
6. "Cómo llegar" — dirección, teléfono, horario, mapa o referencia visual de ubicación.
7. Footer con llamada a la acción y datos de contacto.

**Estilo visual:**
- Paleta inspirada en el Mediterráneo: terracota/tierra quemada, verde marino profundo, papel/arena cálido, dorado como acento — nada de colores genéricos de plantilla.
- Tipografía con carácter: una serif con personalidad para titulares (ej. Fraunces) + una sans limpia para el texto (ej. Work Sans).
- Un elemento visual de firma que conecte el concepto "rizo ↔ ola" (por ejemplo, una animación de líneas curvas dibujándose en el hero).
- Diseño 100% responsive: en móvil, todo se reordena en una sola columna, menú y grids se adaptan.

**Restricciones técnicas:**
- Un solo archivo autocontenido (HTML+CSS+JS), sin dependencias de pago.
- El selector de reservas puede ser una demo visual por ahora, pero dejar comentado en el código dónde iría el embed real de Cal.com/Calendly.
- Debe poder subirse directamente a Netlify o Vercel sin configuración adicional.

---

### Nota de uso
Este mismo prompt sirve de plantilla para el siguiente negocio: cambia los datos del punto "Negocio", el titular del hero (siempre con imagen concreta, no concepto abstracto) y la paleta si el rubro lo pide (ej. tonos verdes para un gimnasio, cálidos para un restaurante), y mantén el resto de la estructura igual.
